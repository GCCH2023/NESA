	要分析函数的参数和返回值，必须先知道它调用的函数的参数和返回值。
比如：
函数A ：
	CALL B
函数B：
	return a
	其中，a 是寄存器。
	显然，a 是函数B的参数，因为函数B没有对 a 赋值就使用了，从而可以推出，
a 也是 函数A 的参数。
	如果不知道函数B是否有参数，则无法确定函数A是否有参数。

注意：函数之间可能存在环状调用关系，比如：A调用B，B调用A
目标：确定每个函数的分析顺序，以分析函数的参数和返回值

	按函数深度来分析，如果一个函数没有调用任何函数，则它的深度是0，最先分析;
否则，函数的深度为它调用的函数的最大深度加一
问题：
	给定一个有向图，如果 节点A 有一条到 节点B 的边，表示节点A依赖于 节点B。
求一个节点序列，这个序列满足：
1. 图的所有节点至少要出现一次
2. 如果 节点A 依赖于 节点B，则 节点B 位于 节点A 前面
	不对，“求”这里有问题。

迭代分析法：
一直迭代：
	分析每个函数，确定它的参数和返回值：
	（1）对于所有非函数调用指令，如果这条指令使用了某个寄存器，并且使用前没有赋值，
	则将这个寄存器作为这个函数的一个参数；
	（2）对于函数调用指令，获取调用的函数的参数信息，如果某个参数传递前未赋值，则
	将这个参数作为这个函数的一个参数；
	返回值
直到所有函数的参数和返回值都保持不变

类型表达式的结合性和优先级
	给定一个变量对象，需要生成它的C语言声明，麻烦的是输出类型。
1. 基础类型，如果 a 是基础类型，则直接输出： 类型 变量名;
	int a;
2. 指针类型，如果 a 是指针类型，则分情况：
(1) 指向基本类型，输出：基本类型* 变量名;
(2) 指向函数类型，输出：？
	算了，很复杂。

	应该根据类型表达式的结合性和优先级来生成声明，从近到远，一层一层地
格式化字符串，新层的字符串可能在后层的前面，也可能在后面。如果优先级比较小的
先格式化，还需要加括号。

2025-3-26
	对于 int (*p)[5]; 这个变量的声明，格式化过程如下：
(1) 首先 p 是指针，指向的类型是数组，数组的优先级大于指针，加括号，输出 (*p)
(2) 格式化数组，先格式化数组元素的类型，插入到已有字符串的前面
(3) 输出数组元素类型 int，得到 int (*p)
(4) 回到数组类型的格式化，格式化数组长度到已有字符串的后面，输出 [5]，得到 int (*p)[5];

	新的问题：函数A内部包含另一个函数B，并且函数B还会跳转到函数A的开始指令。
	目前的函数范围识别算法：认为函数是连续指令组成的，从函数开始地址开始，
一直识别，直接遇到最后一个函数返回指令。
	处理方法：
1. 当作两个函数，并且它们的代码完全相同，需要修改函数范围识别算法，并且函数
范围会有问题。
2. 拆分成两个函数，函数A内联函数的部分改为调用函数B，函数B跳转到函数A的语句改为调用函数A，
需要修改指令，并且判断要不要修改。
	内联函数的判断：
（1）在识别一个函数时，如果这个函数的地址包含在数据库中存在的函数范围内，则它是内联函数；
（2）在识别函数范围时，如果跳转地址在函数之前，那么就认为当前函数是内联函数；
（3）在识别函数范围时，如果一条指令属于数据库中的存在的一个函数，说当前函数内联了数据库中的函数。
