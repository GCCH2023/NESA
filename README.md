# NESA
一个C++20开发的将NES文件反编译为C语言代码的项目。

## ✨ 功能特性

- ✅ 静态函数识别与翻译
- ✅ 基础控制流重构（if/while等）
- 🚧 动态跳转识别（间接JMP）
- 🚧 数组长度推断
- 🚧 更多游戏支持

## 有待改进

1. 更多游戏支持，目前只测试了《超级马里奥》1代，并且只支持 Mapper 0 的 rom 文件；
2. 无法识别动态跳转的函数，比如间接寻址的JMP指令；
3. 无法识别数组长度，仅能判断一个变量是不是数组类型
4. 生成的C代码可读性有待提高
5. ......

## 构建运行项目

按照以下步骤构建运行项目:

1. 克隆仓库:
   ```bash
   git clone https://github.com/GCCH2023/NESA.git
   ```
2. 打开克隆下来的项目文件夹，双击里面的 NESA.sln 文件，使用 Visual Studio 2022 或更高版本的 Visual Studio 打开，
需要支持 C++ 20 标准的编译器;

3. 下载安装 1.87 或更高版本的 boost 库，在Visual Studio 中配置 boost 库目录；

4. 修改 main 函数中的游戏文件路径，使用 Visual Studio 编译运行项目。
